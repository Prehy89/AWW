# AWW — consultation

Lecteur de graphiques précalculés, avec zoom, historique complet et gestes tactiles.
Ce dépôt contient uniquement le lecteur, ses résultats affichables et le nécessaire
à leur déploiement sur GitHub Pages. Aucun moteur financier ni fichier d'import.

## Actualiser

Remplacer **`consultation.zip`** à la racine par le nouvel export de consultation.
GitHub Actions vérifie le contenu, puis publie la version validée.
Les calculs et imports de nouvelles données sont effectués sur le poste de travail.

Pour le premier déploiement, choisir **GitHub Actions** dans Settings → Pages.
Les dates disponibles sont affichées dans le lecteur. Les résultats et cours
visibles sont publics et récupérables ; ils ne constituent pas un stockage privé.
